# The New Order Rises Again


The New Order: Rises Again is a fork of the Hearts of Iron 4 mod The New Order: Last Days of Europe. Rises Again aims to restore classic content, provide a basis for new gameplay driven content, and capture the spirit of fun that drove the TNO hoi4 mod and the forum roleplaying game it was based on.

**Installation**

To install the mod, simply download the project and move it to your hearts of iron 4 mod folder. Copy the descriptor.mod file to the mod folder. If Hoi4 does not recognize the mod, then open the copied descriptor file and copy the TNORAs folder address into `path`.
